# Часть 2. Готовые решения

[На главную](../README.md)

Берём популярные решения, которые можно установить и использовать. На практике исследуем, какие задачи они решают, как устроены, где возникают проблемы и какими средствами эти проблемы можно закрыть.

Опираемся на [общую базу первой части](../01-foundations/README.md): уже можем различать возможности модели, агентного приложения и подключённых инструментов.

Для каждого разбора важны конкретная задача, наблюдаемое поведение, ограничения и результат проверки. Запросы участников помогут выбрать решения и порядок встреч.

Темы и материалы появятся по мере подготовки. Следующий этап — [кейсы участников и улучшение процессов](../03-practice/README.md).
