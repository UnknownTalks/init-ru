# Часть 3. Кейсы и улучшение процессов

[На главную](../README.md)

Участники по желанию приносят реальные кейсы: задачи, текущий способ работы с агентами и возникающие проблемы. UnknownHero исследует их и показывает, что можно улучшить и как рассуждать при поиске улучшений.

Разбор соединяет задачу, доступный контекст, настройки агента, инструменты и способ проверки результата. Улучшение оцениваем относительно задачи: качество, надёжность, время, стоимость и необходимое внимание человека.

Цель — научиться самостоятельно исследовать развитие агентных систем, проверять новые практики и интегрировать их в собственную работу. В процессе также определим несколько универсальных сборок для проектов с нуля.

Публичные материалы разборов появятся по мере проведения встреч и согласования с авторами кейсов.
