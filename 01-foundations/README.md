# Часть 1. Основы и общий язык

[На главную](../README.md)

Разбираемся в принципах работы AI и агентов, чтобы дальше осмысленно тестировать инструменты, понимать их ограничения и объяснять результаты.

Опыт использования агентов полезен, но не заменяет общего языка. Свяжем знакомые слова с конкретными механизмами: данные, обучение, модель, токен, контекст, инструмент, агент. Затем разберём остальные понятия, необходимые для исследования решений, включая MCP и skills.
